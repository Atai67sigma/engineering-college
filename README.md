# Engineering College

Static multi-page brochure website for the fictional Engineering College (HTML5, CSS3, Bootstrap 5, vanilla JavaScript).

## Page map
- `index.html` Home
- `about.html` About and programs
- `admissions.html` Admissions, fees table, FAQ
- `student-life.html` Clubs, events, news
- `contact.html` Contact form
- `registration.html` Registration form

## Features
- Fixed, collapsible top navigation with active states
- Registration form with inline validation and success confirmation
- Contact form with anti-spam question and hidden honeypot field
- Extra interaction 1: category filters on Programs and Student Life
- Extra interaction 2: FAQ expand/collapse all
- Content works without JavaScript

## Known limitations
- Forms do not send data (no server-side code)
- No photographs yet
